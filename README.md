# 🚀 Crypto Trading Signal System

A real-time, event-driven crypto trading signal system built with Python.  
The system connects to Binance WebSocket streams, analyzes live market data using a moving average strategy, and sends automated trading signals to Telegram.

---

## 📌 Overview

This project is a backend trading automation system that demonstrates:

- Real-time data processing
- Event-driven architecture
- Trading strategy implementation
- External API integration
- Scalable Python backend design

It is designed as a foundation for more advanced algorithmic trading systems.

---

## ⚙️ Features

- 📡 Live market data from Binance WebSocket
- 📊 Moving Average (EMA/SMA) trading strategy
- 🚀 Automatic BUY/SELL signal generation
- 📲 Telegram bot notifications in real-time
- 🔄 Auto-reconnect system for WebSocket stability
- 🧠 Modular and scalable architecture
- 🧾 Clean separation of concerns (Engine / Strategy / Services)

---

## 🧰 Tech Stack

- Python 3.x
- WebSockets
- Requests
- Python-dotenv
- Telegram Bot API
- AsyncIO
- Git & GitHub
